Как решать уравнение

Четыре шага + пятый — для задач

  1. Избавься от скобок. Если есть скобки — раскрой их: каждое слагаемое внутри умножай на число перед скобкой. 2(x − 3) = 2x − 6
  2. Перенеси слагаемые. Всё с x — влево, все числа — вправо. При переносе через «=» знак меняется на противоположный. x + 3 = 7  →  x = 7 − 3
  3. Приведи подобные. Сложи все x слева и все числа справа: 3x − x = 2x.
  4. Раздели обе части на коэффициент перед x: 2x = 8 → x = 4.
  5. Задача → уравнение. Обозначь неизвестное за x, переведи условие на язык математики и решай по шагам 1–4.
Ловушка с минусом: если перед скобкой стоит минус — при раскрытии меняются знаки всех слагаемых внутри: −(x + 5) = −x − 5
Ловушка с дробным ответом: ответ может быть дробным — это нормально! Например, в демоверсии ВПР ответ 3,5.

Уравнение

📋 Памятка: правила и ловушки
  • Перенос через «=» — знак меняется на противоположный.
  • Минус перед скобкой меняет знаки всех слагаемых внутри.
  • Подобные слагаемые собираем: x — слева, числа — справа.
  • Дробный или отрицательный ответ — нормальный ответ.
  • Проверка: подставь корень — обе части должны сравняться.
