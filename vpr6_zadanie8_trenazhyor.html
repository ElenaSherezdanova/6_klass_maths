Как решать уравнение

четыре шага к ответу — плюс шаг для задач
1. Избавься от скобок. Если есть скобки — раскрой их: каждое слагаемое внутри умножь на число перед скобкой: 2(x − 3) = 2x − 6.
2. Перенеси слагаемые. Всё с x — влево, все числа — вправо. При переносе через «=» знак меняется на противоположный: x + 3 = 7 → x = 7 − 3.
3. Приведи подобные. Сложи все иксы слева и все числа справа: 3x − x = 2x.
4. Раздели обе части на коэффициент перед x: 2x = 8 → x = 4.
5. Задача → уравнение. Обозначь неизвестное за x и переведи условие на язык математики: «умножить на 4» → 4x, «вычесть 6» → −6, «в 3 раза больше» → 3x. Получится уравнение — решай его по шагам 1–4.
📖 Памятка: правила и ловушки — нажми, чтобы открыть
  • Перенос через «=»: знак меняется на противоположный.
  • Минус перед скобкой: меняет знаки всех слагаемых внутри: −(x + 5) = −x − 5.
  • Подобные слагаемые: иксы — влево, числа — вправо.
  • Ловушка: дробный или отрицательный ответ — нормальный ответ. Например, в демоверсии ВПР ответ 3,5.
  • Проверка: подставь корень — обе части должны сравняться.
