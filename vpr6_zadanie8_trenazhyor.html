📝 Памятка: правила и ловушки — нажми, чтобы открыть
1. Скобки. Если есть скобки — раскрой: каждое слагаемое внутри умножь на число перед скобкой. Пример: 2(x − 3) = 2x − 6.
2. Перенос. Всё с x — влево, все числа — вправо. При переносе через «=» знак меняется на противоположный: x + 3 = 7 → x = 7 − 3.
3. Подобные. Сложи все иксы слева и все числа справа: 3x − x = 2x.
4. Деление. Раздели обе части на коэффициент перед x: 2x = 8 → x = 4.
⚠ Ловушка с минусом. Минус перед скобкой меняет знаки всех слагаемых внутри: −(x + 5) = −x − 5.
💡 Дробный или отрицательный ответ — это нормальный ответ. Например, в демоверсии ВПР ответ 3,5.
✔ Проверка. Подставь найденный корень в уравнение — обе части должны сравняться.
